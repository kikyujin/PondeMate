# Third-party notices

PondeMate is a fork of CrossPoint Reader. This file lists the third-party code,
fonts and data in this repository and in the released `firmware.bin`, with the
license of each and where its license text is. "In firmware" was checked against
the linker map of the `gh_release` build (`.pio/build/gh_release/firmware.map`).
